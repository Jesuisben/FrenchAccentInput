# 문제 해결

## 악상 문자가 입력되지 않음

- 작업 표시줄 알림 영역에 French Accent Input 아이콘이 있는지 확인한다. 종료했다면 다시 실행한다. 이미 실행 중이면 두 번째 실행은 새 인스턴스를 만들지 않는다.
- 일반 권한으로 실행한 프로그램은 관리자 권한 앱이나 보안 데스크톱에 입력할 수 없다. 일반 권한의 편집기에서 먼저 확인한다.
- 왼쪽 `Alt`와 지원 키 `a`, `c`, `e`, `i`, `o`, `u`, `y`를 사용한다. 오른쪽 `Alt`와 지원하지 않는 조합은 원래 앱으로 전달된다.
- 한국어 IME가 `가` 모드이면 한글 입력을 보호하기 위해 원래 키를 통과시킨다. 악상을 입력하려면 `A` 모드로 전환한다. 한국어 IME 상태를 읽지 못한 경우에도 악상 변환을 건너뛸 수 있다.

## 글자 교체 또는 다음 입력이 예상과 다름

- Caps Lock을 끈 상태에서 같은 왼쪽 `Alt` 입력 흐름으로 `e`를 반복하면 `é`, `è`, `ê`, `ë` 순서로 직전 글자를 교체한다. Shift도 함께 누르면 `É`, `È`, `Ê`, `Ë`가 나온다. Caps Lock을 켜면 왼쪽 `Alt`만으로 대문자, Shift까지 함께 누르면 소문자가 나온다. `Alt`를 떼었다가 다시 누르면 새 흐름을 시작한다.
- 포커스나 커서가 바뀌거나 다른 키·마우스 입력이 끼어들면 직전 글자를 교체하지 않는다. 새 흐름에서 다시 확인한다.
- 일부 입력칸은 Unicode 입력이나 기존 글자 교체를 제한할 수 있다. 메모장의 새 빈 문서에서 먼저 비교한다. 입력 차단이 계속되면 앱과 입력칸 종류를 함께 기록한다.

## 설치·종료

- 설치 프로그램은 사용자별 설치 경로를 사용한다. 실행 중인 French Accent Input이 있으면 알림 영역 메뉴에서 종료한 뒤 설치 또는 제거한다.
- 설치 마법사에서 시작 메뉴·바탕화면 바로가기를 선택할 수 있다. 둘 다 해제했다면 설치 폴더의 `FrenchAccentInput.exe`를 실행한다.
- 완료 화면의 **Windows 로그인 시 자동 실행**은 기본 해제다. 이후 알림 영역 아이콘을 우클릭해 **설정**에서 켜거나 끌 수 있다. 로그인으로 자동 실행되면 사용법 창과 실행 알림을 띄우지 않는다.
- 사용법 창의 X는 창만 닫는다. 알림 영역 아이콘을 왼쪽 클릭하면 다시 열린다. 중복으로 직접 실행하면 기존 사용법 창을 연다.
- 프로그램을 종료하려면 알림 영역 아이콘을 오른쪽 클릭해 종료를 선택한다.

## 빌드 도구를 찾지 못함

`scripts/build-release.ps1`은 설치된 CMake와 Inno Setup compiler를 찾는다. Visual Studio Build Tools에서 **Desktop development with C++**와 Windows SDK가 설치됐는지 확인한다. Inno Setup 설치 여부도 확인한다. 빌드 스크립트가 지원하는 도구 경로는 해당 파일에서 확인할 수 있다.

관련 구현은 [`src/main.cpp`](../src/main.cpp), 빌드 설정은 [`CMakeLists.txt`](../CMakeLists.txt)에 있다.
